# Contributing

Contributions should improve reproducibility, clarity, or responsible use.
Please do not submit real student records, credentials, or confidential
institutional information.

1. Open an issue describing the proposed change.
2. Create a focused branch and add or update tests and documentation.
3. Run `pip install -e ".[dev]"` and `pytest` locally.
4. Explain data, modeling, fairness, and privacy implications in the pull
   request description.

Changes that introduce a new model must document intended use, limitations,
evaluation results, and subgroup behavior.
