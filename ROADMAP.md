# Roadmap

## Current

- Synthetic data generation and data-quality checks
- Reproducible logistic-regression baseline
- Performance and subgroup fairness diagnostics
- Responsible-use, governance, deployment, and model-card documentation
- Automated tests and GitHub Actions CI

## Next

- Add temporal splits and drift monitoring
- Add calibration and precision-recall visualizations
- Add intersectional subgroup confidence intervals
- Compare interpretable tree-based models with the baseline
- Execute notebooks and publish reports as CI artifacts
- Add experiment tracking and model/data version metadata
