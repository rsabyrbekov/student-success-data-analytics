# Synthetic data dictionary

`data/synthetic/student_success.csv` is generated by
`src/generate_data.py` with seed `42`. It contains no real student records,
names, contact details, or directly identifying information.

| Column | Description |
| --- | --- |
| `student_id` | Synthetic record identifier |
| `age_band` | Coarse age category |
| `first_generation` | First-generation student indicator (0/1) |
| `financial_aid` | Financial-aid indicator (0/1) |
| `online_student` | Primarily online student indicator (0/1) |
| `credits_attempted` | Credits attempted in the current term |
| `attendance_rate` | Percentage attendance |
| `prior_gpa` | Prior-term GPA on a 0–4 scale |
| `advising_contacts` | Number of advising contacts |
| `persisted_next_term` | Demonstration target: persisted next term (0/1) |
