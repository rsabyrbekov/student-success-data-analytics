# Responsible use

This repository is a teaching and prototyping project. The included data is
synthetic and the baseline must not be used to make automated decisions about
real students.

Before any real-world use:

- Obtain institutional approval, a documented purpose, and appropriate consent
  and privacy protections.
- Minimize data collection and access; follow applicable laws and institutional
  policies, including FERPA or GDPR where relevant.
- Validate data quality, drift, calibration, and subgroup performance locally.
- Include students and support professionals in design and review.
- Use predictions only as one input for voluntary, supportive outreach.
- Provide human oversight, an appeal path, and clear explanations.
- Never use protected characteristics to deny services, discipline students,
  or label a student as incapable of success.
