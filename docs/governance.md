# Governance checklist

Before using institutional data or deploying a model, record the accountable
owner, purpose, approvals, data inventory, lawful basis, retention schedule,
access roles, provenance, split strategy, reproducible configuration, overall
and intersectional performance, calibration, subgroup disparities, uncertainty,
human review, student notice, correction/appeal process, incident response,
monitoring cadence, and rollback owner.

Re-review after material data, feature, threshold, model, or policy changes.
Keep synthetic examples separate from institutional records and never commit
student records, credentials, or artifacts containing personal data.
